# 互斥与竞态首个切片来源页映射

记录时间：2026-07-19

## 状态与边界

本文为 D-011 已选择的“互斥与竞态条件”纵向切片定位本地候选来源页。它只记录文件名、1-based 页码、通用主题标签、用途和保真风险，不复制课件正文、图片、代码或原题。

课件再分发许可证未知，因此这些 `SourceReference` 只能在学生本机解析和显示；不得把 PDF、页面截图或抽取正文提交到 Git、测试夹具、公开演示或分发产物。

## 扫描方法

1. 只读扫描以下四份本地 PDF：多处理器编程、互斥、互斥进阶、并发 bugs；
2. 使用 `pypdf` 对每页做 NFKC 归一化，只统计共享状态、竞态、原子性、交错、临界区和互斥/锁等通用信号；
3. 不把抽取正文写入文件，只输出页码、标签、信号数、非空白字符数和图像对象数；
4. 使用 `pypdfium2` 临时渲染 7 个高信号页，并以联系表人工检查图、代码、箭头和文字是否清晰；
5. 检查后删除扫描脚本；渲染页和联系表的删除被托管环境策略拒绝，已放在 Git 忽略的 `tmp/`，不提交或分发。

`pypdf` 继续报告既有的 `Ignoring wrong pointing object` 可恢复警告；四份文件均完成读取，没有页级异常。本次信号统计用于缩小人工检查范围，不是内容正确性或课件保真度证明。

## 来源选择不变量

1. `SourceReference` 保存内容哈希、文件身份、1-based 页码、解析版本和质量标记；文件名不能作为唯一身份。
2. 页面截图与抽取文本保持独立引用；任何归一化不得覆盖原始抽取。
3. M2 只有在页面仍存在且版本匹配时才能把输出标为“基于课件”。
4. 页面图中的颜色、时间轴、箭头、代码缩进或分组无法可靠转成文本时，显示保真警告并提供原页对照。
5. 本地模式只使用本机数据；按页云端模式逐次预览实际页；不得因为候选页列表存在就预授权上传。
6. 正式题目使用合成线程/变量和参数化轨迹，不复刻课件原题或受限代码。
7. 删除或替换课件后，旧来源进入不可用/待重映射状态，不能静默指向同页码的新内容。

## 可转为测试的来源行为

- 内容哈希不变时重新导入可复用来源身份；哈希变化时旧 `SourceReference` 不自动改绑；
- 页码越界或材料删除后，解释请求失败关闭且 provider mock 调用为 0；
- 本地模式获取候选来源不会产生远端调用；
- 按页云端模式的请求范围严格等于用户当次确认的页面集合；
- 抽取质量标记为低时仍可打开原页，不把警告当作上传授权；
- provider 输出引用不存在页面时不能保存为课件事实；
- 合成轨迹 oracle 与课件内容解耦，删除课件不会改变既有题目参数的正确结果，但会使来源说明不可用。
