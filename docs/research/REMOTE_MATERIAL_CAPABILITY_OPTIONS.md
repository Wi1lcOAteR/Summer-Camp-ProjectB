# 第一版远端课程材料能力候选

记录时间：2026-07-20T00:51:22+08:00

## 决策范围

已确认的不变量：第一版单用户、本地优先；用户首次导入时显式选择处理方式；选择按课程记住；低保真检测不得静默上传；扩大外发范围必须再次确认；模型只能通过受约束端口处理已批准来源。

本决策只回答“第一版产品提供到哪一级远端材料能力”，不选择 provider、模型、数据区域、留存政策、价格或凭据实现。它也不决定某门课程具体选择哪种模式，那仍由用户在导入引导中决定。

## 三种能力目录

| 维度 | 1. 本地 + 按页远端 | 2. 本地 + 按页 + 整份远端 | 3. 完全本地材料 |
| --- | --- | --- | --- |
| 本地解析/原页对照 | 有 | 有 | 有 |
| 经确认页面/片段远端多模态 | 有 | 有 | 无 |
| 整份 PDF/课程上传 | 无 | 有 | 无 |
| 用户可选模式数 | 2 | 3 | 1（可有本地解析策略变体） |
| 视觉保真补救 | 逐页、任务级 | 逐页或整份 | 原页人工核对/本地模型 |
| 版权/隐私外发面 | 有界到已批准页面 | 最大 | 最小 |
| 远端删除复杂度 | 请求/缓存引用 | 文件、索引、缓存和任务 | 无课程材料远端对象 |
| 分发/硬件负担 | 中 | 中至高 | 高（若要求本地模型） |
| 第一版测试负担 | 中 | 高 | 中至高 |

## 方案 1：本地解析 + 经确认页面/片段远端处理（推荐）

课程始终在本地建立原页、抽取文本、质量报告和索引。学生可以选择：

- **本地模式**：课程正文不离开本机，解释只使用本地解析/规则或之后另选的本地模型能力；
- **按页高保真模式**：每次模型任务展示将发送的页面缩略图、页码、片段、用途、provider 和预算，用户确认后才调用远端端口。

这仍然满足“把选项留给用户”：用户能在数据不外发和按任务提升视觉理解之间选择；只是第一版不提供风险最大的整份文件上传。选页来源可以由本地检索提出，但扩大或首次远端请求必须可见且可删减。

最低测试：无确认调用为 0；捕获请求只含批准来源；同意记录和请求范围一致；页面被删除/撤销后不能复用；provider 失败不改变课程模式或计划。

## 方案 2：再增加整份 PDF/课程云端处理

在方案 1 之外，允许用户把完整 PDF 或课程文件集合上传到 provider 的文件/知识库接口。该模式可能减少选页遗漏并利用供应商长上下文/文档能力，但必须额外设计：

- 文件级独立授权、权利/敏感内容提醒和总大小/成本预估；
- 上传、解析、索引、可用、失败、删除中、删除不完整状态；
- 供应商文件 ID、索引 ID、留存/训练政策、区域和过期策略；
- 切换回更严格模式后的远端文件/索引删除与不可保证项；
- 证明解释引用具体页，而不是把整份文件存在远端当成来源正确性；
- 公共演示绝不使用真实受限课件。

最低测试除方案 1 外，还包括分片/重试幂等、部分上传失败、索引未完成、删除失败、供应商对象泄漏、过期清理和大文件预算终止。

## 方案 3：课程材料完全不外发

PDF、页面图、抽取和索引始终留在本机。模型若需要课程内容，只能使用本地部署模型；否则远端模型只能处理用户手工输入且不包含受限课程片段的通用问题。

它的数据边界最清晰，但可能无法解决学生最初提出的视觉/版面失真问题，除非第一版同时承担本地多模态模型、硬件检测、模型分发、离线更新和性能优化。用户选择空间也会从“数据边界选项”退化为本地解析工具差异。

## 共同安全合同

1. 课程创建后仍处于 `awaiting_policy`，没有显式选择就不解析正文或外发。
2. 课程模式是能力授权上限，不代表每次远端调用自动获准；每个请求仍受端口、来源、用途和预算约束。
3. 模式切换只能保持或收紧范围；扩大范围创建新的 `ConsentRecord`，不覆盖旧记录。
4. 模型输出、材料正文和页面图均无工具权限；提示注入不能改变模式或上传范围。
5. 本地原页始终是可核对来源；远端解析不能覆盖原文件、原始抽取或用户修正。
6. 删除显示本地与远端各自状态；无法证明远端删除时显示 `delete_incomplete`。
7. 日志不保存课件正文、页面图、文件路径、学生作答或凭据。

## 推荐理由

推荐方案 1。真实材料已证明本地抽取并非空白，但视觉语义需要原页；按页远端能补足公式、图表、代码分组和时序图理解，同时把外发、成本、引用和删除控制在可验收范围内。整份模式的主要收益依赖尚未选择的 provider 能力和材料权利，而它会在第一版提前引入远端文件生命周期。

如果学生明确认为“用户必须能选择整份 PDF 远端处理”是核心体验，则选择方案 2，并接受额外生命周期与版权验收。方案 3 只有在课程材料绝不外发是硬约束时更合适。

## 选择后的影响

- 选择方案 1：SPEC 的正式模式目录为 L/P；模式 F 作为延期项，PLAN 不实现远端文件生命周期。
- 选择方案 2：SPEC 加入 F 的上传/索引/删除状态与验收；后续 provider 选择必须支持明确文件生命周期和删除语义。
- 选择方案 3：SPEC 删除课程内容远端端口，重新评估本地模型、硬件、分发和视觉保真验收，不能只关闭网络后沿用现有承诺。
