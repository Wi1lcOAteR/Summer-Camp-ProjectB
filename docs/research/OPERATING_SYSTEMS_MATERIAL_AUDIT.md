## 技术可读性验证

- 15 份 PDF 均未加密，首页尺寸均为 1920 × 1080 points，对应 16:9 幻灯片。
- 每份 PDF 的前三页均提取到非空文本，能识别中文标题、英文术语和部分公式/代码字符。
- `pypdf` 对多份文件报告 `Ignoring wrong pointing object` 容错警告，但所有文件的页数和抽样文本均成功读取。正式产品必须把“可恢复警告”和“解析失败”区分记录，不能静默吞错。
- bundled Poppler 包装器在当前沙箱中找不到内部路径；系统 MiKTeX `pdftotext` 尝试写用户配置目录时被拒绝。审计改用 bundled `pypdf`/`pypdfium2`，未修改用户级配置。
- 使用 `pypdfium2` 临时渲染绪论、并发、虚拟化、持久化各一页，四张 1440 × 810 图像均清晰显示；检查后已删除临时图。
- 后续对全部 932 页做文本/资源结构统计：0 个空文本页、95 个少于 100 个非空白字符的页面，文本中位数 226 字符/页；全部页面的 NFKC 归一化结果与原抽取不同，0 个 `U+FFFD` 替换字符，页面级提取异常为 0。
- 932 页均含图像 XObject，87 页含 Form XObject；这些对象可能只是校徽、背景或矢量容器，因此只证明需保留原页对照，不能作为视觉语义完整性的自动判定。
- 详细处理模式与统计边界见 `docs/research/COURSEWARE_PROCESSING_MODES.md`。

## 内容形态

抽样页表明课件不是纯文本材料，至少包含：

- 中英双语概念与术语；
- 代码、API 名称、数学集合与状态机表达；
- 图表、架构/流程图和图片；
- 示例、类比、事故案例与课堂提问；
- 单页信息密度差异明显的讲义式幻灯片。

因此，后续材料处理不能只保留一段无页码的纯文本。解释、练习和引用至少要能回到“课件文件 + 页码/幻灯片”，视觉信息无法可靠抽取时还要向用户标示限制。统一 `SourceLocator` 判别联合为：`pdf_page` = `{kind, material_id, content_hash, page, region?}`，`image` = `{kind, material_id, content_hash, image_id, region?}`，`text_lines` = `{kind, material_id, content_hash, line_start, line_end}`，`manual_entry` = `{kind, entry_id, version}`；本审计只验证了 `pdf_page` 所需的文件/页级基础信息。

## 对候选产品的约束

1. **最小数据层级**：课程 -> 主题组 -> 课件 -> 幻灯片 -> 知识点；知识点可以跨多份课件出现。
2. **可追溯解释**：基于课件的解释必须附有效且版本匹配的 `SourceLocator`，区分课件原意、无权威材料引用的系统补充和学生当次作答/自我解释；个人笔记作为导入材料延期。OpenAI File Search citation 不能直接替代本地页码映射。locator 映射失败时，coverage/exam 分析返回空候选 + `source_insufficient`，解释/练习/反馈只能作为 `model_supplement`，不能进入课程事实、计划或掌握证据。
3. **多模态边界**：首版至少要保存幻灯片图像与抽取文本的对应关系；已授权 P 请求可让 OpenAI 直接处理页面/PDF/图片，F 可使用 Files/每课程独占 Vector Store，但都必须受同意、来源映射、政策快照和删除对账约束。
4. **增量复习闭环**：课件不假设在学期初一次性齐全；每个新批次先形成候选覆盖，由学生确认可学习/可复习知识后再修订计划，复习结果继续更新同一知识状态。
5. **失败可见性**：解析警告、无文本页、公式/代码损坏和图片缺失必须呈现，不能把不完整抽取冒充完整材料。
6. **期末材料角色**：第一版只允许无答案往年卷和老师给定重点作为后续批次；二者必须与课件区分角色、映射到已确认知识并保留来源/置信度。文件形式支持 PDF、图片和文本，重点还可手工录入；本审计尚未验证这些导入路径。相关分析只覆盖结构、题型、知识点与难度，不包含训练或原题预测。
7. **版权与隐私**：默认不上传整套课件、不公开缓存、不随应用分发；云端处理范围必须由学生明确确认，新增批次不会继承更宽的临时许可。
8. **容量基线**：真实样本约 195 MB、932 页，落在 M1 v1 的批次上限（50 文件、1 GiB、5,000 PDF 页）内；这只证明样本规模适配合同，不证明性能达标。v1 还限制 `.pdf` + `application/pdf`/PDF 魔数单文件 256 MiB/2,000 页，PNG/JPEG/WebP 对应标准扩展名/MIME 为 20 MiB/50 megapixels，UTF-8/UTF-8 BOM TXT/Markdown 对应 `text/plain`/`text/markdown` 为 2 MiB，手工重点 1-10,000 code points；任一变化都需新合同版本。
9. **调度数值边界**：195 MB、932 页和 15 份课件不是调度参数依据。最新 SPEC 独立提出 `ReviewPolicy v1` 数值/纯函数候选，须整体签字；这些数值不宣称源于课件或科学最优。
10. **角色与人工复核**：明确答案/延期角色在正文处理前返回 `unsupported_role`；本地解析后发现疑似答案或泄露迹象进入 `needs_user_review`，远端调用和权威覆盖/计划写入为 0。自动检测不能声称识别全部泄露内容。
11. **考后与删除**：考试当天仍可学习，仅 `today_local > target_local_date` 后进入 `post_exam_paused`。材料删除后本地正文/页面/抽取/可重建索引不可检索，历史只留不含正文、路径或 provider ID 的 tombstone/失效 locator。

D-011 选择后的首轮来源页只读映射与视觉抽样见 `docs/research/MUTEX_RACE_SOURCE_MAP.md`；该文件不包含课件正文或图片。
